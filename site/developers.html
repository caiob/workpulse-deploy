Quickstart

Quatro passos.
Cinco minutos.

Do zero ao primeiro evento ingerido em menos tempo do que leva para fazer um café.

  1. 1

    Subir o servidor

    Docker em uma linha ou Python local — você escolhe.

  2. 2

    Emitir uma licença

    Token Ed25519 assinado pelo seu próprio servidor.

  3. 3

    Configurar o agente

    Cole o token no config.toml e inicie.

  4. 4

    Consultar a API

    Eventos sincronizam automaticamente em lote.

# 1. Servidor com persistência em volume Docker
$ docker run -d --name workpulse \
  -p 8080:8080 \
  -v workpulse-data:/data \
  -e WORKPULSE_DB=/data/workpulse.db \
  -e WORKPULSE_ADMIN_TOKEN=$(openssl rand -hex 32) \
  ghcr.io/workpulse/server:1.0

# 2. Verificar saúde
$ curl http://localhost:8080/healthz
{"status":"ok","version":"1.0.0"}
# Python 3.11+ direto, sem Docker
$ git clone https://github.com/workpulse/workpulse
$ cd workpulse/server
$ python3.11 -m venv .venv && source .venv/bin/activate
$ pip install -r requirements.txt
$ export WORKPULSE_ADMIN_TOKEN=$(openssl rand -hex 32)
$ python -m main # lê WORKPULSE_LISTEN
# Imagem on-premise air-gapped
$ docker load < workpulse-server-1.0.tar
$ docker run -d --name workpulse \
  --network workpulse-vlan \
  -v /etc/workpulse/keys:/keys:ro \
  -e WORKPULSE_LICENSE_PRIVKEY=/keys/license.key \
  workpulse/server:1.0
Referência

API REST.
Versionada. Estável. Auditável.

Todas as respostas em JSON UTF-8. Erros seguem RFC 7807. Autenticação por X-Admin-Token (operadores) ou Authorization: Bearer com chave de licença (agentes).

Agentes

POST /v1/ingest Recebe lote de eventos de um agente
POST /v1/license/heartbeat Verifica se a chave continua válida

Workforce

GET /v1/workforce/overview KPIs agregados, alertas, breakdown por departamento
GET /v1/workforce/timeseries Séries temporais para gráficos de tendência
GET /v1/users Lista de colaboradores do tenant
GET /v1/users/{id}/summary Drill-down individual com séries diárias
GET /v1/team/summary Tabela de produtividade da equipe
GET /v1/events Busca paginada de eventos brutos

Plataforma

GET /v1/admin/tenants Inventário de tenants com contagens agregadas
GET /v1/admin/licenses Inventário de licenças com status e dias restantes
GET /v1/admin/stats Estatísticas do servidor: ingestão, banco, distribuição
GET /v1/admin/audit Log de ações administrativas
POST /v1/license/issue Emite uma nova chave assinada Ed25519
POST /v1/license/revoke Marca chave como revogada (efeito em ≤30 min no agente)
Webhooks · Plano Business+

Eventos em tempo real.
Onde sua equipe estiver.

Receba notificações HTTP assinadas (HMAC-SHA256) sempre que algo importante acontecer no tenant. Reentregue automaticamente em caso de falha.

user.first_seen Novo colaborador apareceu pela primeira vez no tenant comum
user.idle_anomaly Usuário com desvio significativo do padrão histórico smart
workforce.overwork_detected Mais de 10 horas de atividade em um único dia alerta
license.expiring_soon Licença expira em menos de 30 dias aviso
license.revoked Licença foi revogada manualmente pelo administrador crítico
device.offline_72h Dispositivo sem sincronizar há mais de 72 horas aviso
